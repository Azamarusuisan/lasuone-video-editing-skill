# ラスワン編集 QC

Version 0.1 / LEARNING_IN_PROGRESS。未チェックは未合格。チェックリストの存在は実施済みを意味しない。

## 学習完了ゲート

- [ ] 189本の公開一覧と未取得・削除・非公開・年齢制限を区別。
- [ ] 各動画の確認済み区間を保存。取得・ASR・差分解析だけで「全編視聴済み」にしない。
- [ ] ベガス長編4本を全編分析し、通常回・再編集・Shortsの重複を紐づける。
- [ ] 最低50〜100の字幕サンプルを文脈と映像で確認。独立イベント数・同じ字幕の継続を区別。
- [ ] カット・無音・強調・反応・ズームの実測値と対象区間を保存。
- [ ] 字形照合、文字サイズ／字形高／OCR枠の区別、縁・影・光彩、色・位置を検証。
- [ ] BGM/SEの実聴取と同期計測、鳴らさない判断を記録。
- [ ] 各ルールのREFERENCE、CONFIDENCE、反例を保存。3動画条件に素材重複を数えない。
- [ ] 長尺・Shorts・Podcast・密着・バカラ・ポーカーを平均化しない。

## 素材と構成

- [ ] 全素材のファイル、尺、解像度、FPS、音声、内容・話者、品質、時系列、用途を記録。
- [ ] マルチカメラの同期、重複、表情・音質・ピント・画角で選定。
- [ ] 全文ASRを固有名詞・数字・意味で校正。未確認箇所は明示。
- [ ] 発言別にSPEAKER / TIMECODE / TEXT / EMOTION / IMPORTANCE / SUBTITLE / ASSET / BGM / SE / CUT / ZOOMを記録。
- [ ] フック候補5個以上を比較。存在しない事件・未回収の煽りを作らない。
- [ ] 伏線の回収、タイトル・サムネイルの約束、冒頭15秒・30秒・1分・3分・中盤・山場前の継続理由を確認。
- [ ] 数字だけで発言を削らず、冗談・沈黙・ミス・気まずさの役割を判断。

## TECHNICAL QC

- [ ] 黒フレーム・音飛び・フリーズ・オフライン素材・字幕切れ・不要な黒帯を検査。
- [ ] 元から意図された黒画面・黒帯を誤検出で消していない。
- [ ] 入出力解像度、FPS、色空間、音声チャンネル、コーデック、ビットレートを記録。
- [ ] クリッピング、真のピーク、全編音量、フェード切れ、位相やノイズ処理の副作用を確認。
- [ ] 話者の声質を過度なAI処理で変えていない。
- [ ] モザイクの追跡漏れをフレーム単位で確認。

## CONTENT QC

- [ ] 人名、会社、施設、馬名、地名、ゲーム用語を校正。
- [ ] BET額／通貨／払戻／純利益／軍資金／累計を別フィールドとして照合。
- [ ] ポーカーの点数、K表記、現金を混同しない。未知のハンドを捏造しない。
- [ ] バカラのWIN/LOSE/PUSH、カード・点数・コミッション等を適用ルールに基づいて確認。
- [ ] 本人と同行者の収支を混同しない。換算金額は基準を明記。
- [ ] 後続の訂正を元表示へ紐づけ、「推定」「以上」等の限定を保持。矛盾するBET／損失額は原因確認まで確定しない。
- [ ] 時系列変更で勝負結果・発言・人間関係を誤認させない。
- [ ] 字幕の短縮・改行で意味を変えない。
- [ ] 実写資料と生成画像を区別する。

## STYLE QC

- [ ] 最新の同フォーマット参照を優先。実験回1本だけで正式スタイルを変更しない。
- [ ] 字幕量・非字幕発言、フォント・縁・色・位置・動きを実証済み参照と比較。
- [ ] 同一場面のカット密度・保持する間・リアクション尺を比較。
- [ ] BGMが鳴りっぱなし、ズーム／SE過多、長尺へのShorts式字幕移植を確認。
- [ ] 高額だから自動で巨大字幕や強SEにしていない。
- [ ] 勝負に集中する区間のB-roll・説明を過剰にしない。
- [ ] 最新実写EDに古いイラストEDを自動移植していない。

## LEGAL QC

- [ ] 各素材のSOURCE / RIGHTS_STATUS / USAGE_REASONと許諾文書を記録。
- [ ] UNKNOWN素材を完成動画で使用しない。公開チャンネルで使われているキャラ・音楽・映像も別途確認。
- [ ] フォント・BGM・SE・ロゴ・記事・SNS・地図の利用条件を確認。
- [ ] 個人情報・周囲の人・ナンバー・書類・画面を確認。
- [ ] GENERATED_ASSETタグを保存。生成を実在人物・ニュースの実写資料として扱わない。
- [ ] ログイン・支払い・資格情報の画面は扱わず、必要ならユーザーへ引き継ぐ。
- [ ] 動画・タイトル・サムネイルを依頼なく公開しない。

## 比較・修正・提出

- [ ] 関連する既存3〜5本をフォーマット・時期・企画で選定し、比較区間を保存。
- [ ] CUT / SUBTITLE / FONT / COLOR / BGM / SE / ASSETS / PACING / COMEDY_TIMING / TENSION_TIMINGの根拠・不足を説明。
- [ ] 未観測項目を満点や平均点で埋めない。CHANNEL_MATCHは同じ採点基準で算出する。
- [ ] 90未満なら原因分析→修正→再評価。根拠不足なら点数ではなく未評価とする。
- [ ] FINAL CHANNEL MATCH SCOREは実際の完成動画にのみ表示。
- [ ] V1/V2/V3と変更点・参照・理由・信頼度をEDIT DECISION LOGへ保存。
- [ ] ユーザー修正をUSER CORRECTION DATAへ保存。特殊回1件では一般ルールを上書きしない。
- [ ] 動画内からサムネイル候補5枚を抽出し、タイトル候補とは別管理。
